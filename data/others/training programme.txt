GOOD HABIT TRAINING PROGRAM
"Know Yourself, Know Others"
==================================================

1. PROGRAM OVERVIEW
--------------------------------------------------
Program Name       : Know Yourself, Know Others
Provider           : Good Habits (in collaboration with YES Professional Advancement Center)
Program Type       : Corporate Training (HRDC Claimable)

Description:
This program is designed to enhance self-awareness, interpersonal skills, 
empathy, communication, and teamwork. It uses experiential learning based 
on Kolb’s Experiential Learning Cycle to promote a collaborative workplace, 
improve performance, and increase job satisfaction.

Available Formats:
- Public Training (2 Days)
- In-House Training (Customizable)
- 1-Day version (simplified format)

--------------------------------------------------
2. KEY PROGRAM HIGHLIGHTS
--------------------------------------------------
- Interactive Learning
  • Hands-on activities for self-discovery and teamwork

- Diverse Methodologies
  • Combination of lectures, performances, discussions, games, and reflection

- Focus Areas
  • Empathy and communication
  • Trust-building
  • Emotional management
  • Workplace application

- Experiential Learning Model (Kolb’s Cycle):
  1. Concrete Experience (Feeling)
     - Engage in activities
  2. Reflective Observation (Watching)
     - Observe and discuss experiences
  3. Abstract Conceptualization (Thinking)
     - Analyse and understand concepts
  4. Active Experimentation (Doing)
     - Apply skills in real-world situations

- Debriefing Sessions
  • Reflection and feedback after each activity
【1-8eaf96】

- Build emotional intelligence for daily and professional life
